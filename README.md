# langsim

외국어로 말해야 살아갈 수 있는 작은 세계 — 언어학습 시뮬레이션.
지금은 **첫 장면 "아침, 방 안"** 하나만 있습니다 (한국어).

## 실행하기

설치할 것은 없습니다. 정적 웹앱(HTML/CSS/JS)이라 빌드 과정도 없습니다.

- **GitHub Pages**: 저장소 Settings → Pages 에서 이 브랜치의 루트(`/`)를 고르면 그대로 돌아갑니다.
- **내 컴퓨터에서**: 이 폴더에서 `python3 -m http.server` 를 실행하고 브라우저로 `http://localhost:8000` 을 엽니다.
  (`index.html` 을 더블클릭해서 열면 브라우저가 json 파일 읽기를 막아 동작하지 않습니다.)

## 장면 흐름

1. 어두운 화면 → **눈을 뜬다** → 방이 보입니다.
2. 침대(장난 반응) · 문(잠김, 자물쇠 표시) · **창문(열림, 친구 등장)**.
3. 친구가 말을 걸고, 선택지를 골라 2~3번 대화가 오간 뒤 “나중에 봐!”로 끝납니다.

화면 왼쪽 위 **langsim** 로고를 누르면 언제든 첫 화면으로 돌아갑니다.
오른쪽 아래 **수준 − / +** 는 테스트용입니다. 수준 이하의 선택지만 보입니다.

## 폴더

```
index.html          화면 틀
style.css           모양
app.js              흐름 제어 (대사 원문 없음)
scenes/scene1.json  상황 층: 장소·물건·인물·대화 순서 (대사는 key 만)
lang/ko.json        언어 층: 한국어 대사 (채워 있음)
lang/en.json        언어 층: 영어 (빈 틀)
lang/zh.json        언어 층: 중국어 (빈 틀)
assets/             그림 (SVG). 파일만 바꾸면 그림 스타일이 바뀝니다
```

## 언어 파일 쓰는 법 (`lang/ko.json` 등)

코드를 몰라도 고칠 수 있게 한 줄에 하나씩 적혀 있습니다.

```json
"friend.greet":     { "level": 1, "text": "안녕! 잘 잤어?" },
"me.reply.3":       { "level": 2, "text": "조금 늦게 잤어. 너는?" },
```

- **왼쪽 key(`friend.greet`)는 고치지 마세요.** `scenes/scene1.json` 에 적힌 이름과 같아야 합니다.
- **text** — 화면에 보이는 말. 마음대로 바꿔도 됩니다.
- **level** — 1(가장 쉬움) ~ 5. 플레이어 수준 이하의 선택지만 보입니다.
  각 질문마다 level 1 선택지가 적어도 하나는 있어야 합니다.
- key 앞부분의 뜻:
  - `friend.` 친구가 하는 말
  - `me.` 주인공의 선택지 (예: `me.reply.1~3` 은 `friend.greet` 에 대한 대답)
  - `narration.` 물건을 눌렀을 때 나오는 안내 글
  - `ui.` 버튼과 안내 문구 (level 은 쓰이지 않음)
- 저장한 뒤 브라우저를 **새로고침**하면 바로 바뀝니다. 코드는 고칠 필요 없습니다.
- 주의: 따옴표(`"`)와 줄 끝 쉼표(`,`)를 지우지 마세요. 마지막 줄에는 쉼표가 없습니다.
  형식이 깨지면 화면 아래에 빨간 안내가 뜹니다.
- 글이 빠진 key 는 화면에 `[key 이름]` 으로 보여서 무엇이 빠졌는지 알 수 있습니다.

영어·중국어를 시작하려면 `lang/en.json` / `lang/zh.json` 의 `"text": ""` 를 채우세요.
text 가 하나라도 채워지면 로고 옆 언어 메뉴에서 고를 수 있게 됩니다 (그 전에는 “준비 중”).

## 대화를 바꾸거나 늘리려면 (`scenes/scene1.json`)

대화는 `dialogue.nodes` 안의 마디들로 이어집니다. 마디마다 친구의 말(`lineKey`)과
선택지(`choices`: 선택지 key 와 다음 마디 `next`)가 있고, `"end": true` 인 마디에서 장면이 끝납니다.
새 key 를 만들었다면 언어 파일에도 같은 key 를 넣어야 합니다.

## 나중을 위해 비워 둔 자리

- **직접 타이핑 입력**: `app.js` 의 `settings.inputMode` (`"choice"` | `"typing"`) 와 `renderTyping()`.
  지금은 `"typing"` 으로 바꿔도 보기 고르기로 대신합니다.
- **AI 친구**: 친구의 다음 말을 정하는 곳은 `app.js` 의 `decideFriendReply()` 함수 하나뿐입니다.
  지금은 선택지에 적힌 `next` 를 따르고, 나중에 이 함수만 LLM 호출로 바꾸면 됩니다.
